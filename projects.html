Potential Research Projects

Projects available to students who want to work with our group.

Each project below is labelled with the level it suits best. PhD students will generally work on two projects, usually one focused on a search and one on reconstruction or software, so that they finish with both a physics result and a technical specialty. Capstone projects are scoped to a single question that can be answered in a year.

If any of these interest you, or if you have an idea of your own, please get in touch at burzynski@ou.edu.

Emerging jets in full Run 3 PhD Capstone

Our first emerging jet search used only part of the Run 3 dataset. This project extends it to the full dataset and pushes the tagging further with transformer taggers and anomaly detection, so we are not limited to the models we thought to simulate.

  • ATLAS, Search for emerging jets in Run 3 (arXiv:2505.02429)
 Dark shower phenomenology and model building Capstone

Dark sectors can shower and hadronize much like QCD does, and the resulting signatures depend strongly on parameters that are poorly constrained. This project maps out which experimental signatures dominate where in the parameter space, and looks for the corners nobody is covering.

 Search for dark photons in full Run 3 PhD Capstone

Dark photons are one of the simplest portals to a hidden sector, and long lifetimes leave displaced vertices in the ATLAS Inner Detector. This project carries out the search in the full Run 3 dataset.

 Optimization of large radius tracking for Run 4 PhD

Large radius tracking is what makes displaced signatures visible, and it has to survive the pileup and rate conditions of Run 4. This project retunes and optimizes the algorithm for the upgraded detector.

  • ATLAS, Performance of large impact parameter track reconstruction (arXiv:2304.12867)
 Track reconstruction with machine learning for the HL-LHC PhD Capstone

Classical tracking scales badly with pileup, so the HL-LHC needs something faster. This project develops transformer and graph based reconstruction, including work on efficiency, fake rates, and the displaced tracks that these models tend to miss.

  • Transformers for Charged Particle Track Reconstruction (arXiv:2411.07149)
  • Better Queries, Cheaper Attention (arXiv:2606.17631)
 Muon collider track reconstruction with 4D tracking Capstone

A muon collider drowns its detector in beam induced background, and precise timing on each hit is one of the few handles that can cut through it. This project studies how 4D tracking recovers real tracks in that environment.

 Trigger development for Run 4 PhD

Anything the trigger does not record is lost forever, and long-lived particle signatures are exactly the ones standard triggers were not designed for. This project helps design the LLP trigger menu for Run 4.

 Reinterpretation of ATLAS long-lived particle searches PhD Capstone

Every search we publish constrains far more models than the ones it was designed for, but only if someone does the work. This project builds tools to recast our displaced vertex and emerging jet results onto new models using published efficiency maps and likelihoods.

 A public benchmark for displaced tracking Capstone

There is no common dataset for testing displaced track reconstruction, so every group measures performance its own way. This project builds an open benchmark with simulated long-lived particle decays and a set of metrics that everyone can use.

  • ATLAS, Performance of large impact parameter track reconstruction (arXiv:2304.12867)
  • Transformers for Charged Particle Track Reconstruction (arXiv:2411.07149)
 Displacement aware jet substructure observables Capstone

Machine learning taggers work well on dark showers but are hard to interpret. This project designs substructure observables built from track impact parameters and measures how much of the tagger performance simple, understandable variables can recover.

  • ATLAS, Search for emerging jets in Run 3 (arXiv:2505.02429)
 Machine learning for beam induced background rejection at a muon collider Capstone

Beam induced background at a muon collider is overwhelming but also highly structured, which is exactly the kind of problem machine learning is good at. This project develops algorithms that separate real collision products from that background.
